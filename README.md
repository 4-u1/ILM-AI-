# 📖 عِلم | ILM — Interactive Islamic Learning & Mentorship Platform
> **منصة دعوة وتعليم دعوي ذكية بالذكاء الاصطناعي التوليدي وتقنية RAG**
> *مشروع فريق NEX المشارك في «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي» — باذل 2026م*

---

## 🌟 نظرة عامة (Overview)
**«عِلم | ILM»** منصة تعليمية ودعوية رقمية تدمج بين دقة العلوم الشرعية المعتمدة وقوة الذكاء الاصطناعي التوليدي المؤطر. تهدف المنصة إلى استبدال أسلوب التلقي النمطي برحلات معرفية تفاعلية متدرجة مخصصة للمسلم وغير المسلم والمسلم الجديد والداعية، مع ضمان الإسناد الفوري بنسبة 100% لمصادر موثقة وتطبيق سياج حماية شرعي حاسم.

---

## 🚀 الركائز التقنية الأساسية (Key Architectural Pillars)
* **المعلم الحواري الذكي (AI Mentor):** أسلوب تدريس حواري نشط (*Learna-Style*) يقسم الدرس إلى كبسولات معرفية لا تنتقل لنقطة تالية إلا بعد قياس فهم المستخدم تفاعلياً.
* **محرك الـ RAG الشرعي الموثوق (Verified RAG):** استرجاع دلالي مغلق مقيد حصراً بمصادر معتمدة (مجمع الملك فهد لطباعة المصحف الشريف، موسوعة الدرر السنية، المستودع الدعوي الرقمي، المكتبة الشاملة).
* **سياج الحماية الشرعية (Strict Guardrails):** نظام عزل وتصعيد فوري يمتنع آلياً عن الفتوى في النوازل والأحوال الشخصية ويحيل للمرجعيات الرسمية المختصة.
* **محاكي الدعوة التفاعلي (Daiyah Simulator):** بيئة محاكاة واقعية لتدريب الدعاة على مناقشة الشبهات وتحليل الأداء الاستدلالي والإقناعي فورياً.
* **نظام التحفيز والشهادات الرقمية:** تتبع سلسلة التعلم اليومية (*Daily Streak Counter*)، وأوسمة الإنجاز الرقمية (*XP Badges*)، وشهادة إتمام مسار رقمية قابلة للتحقق والطباعة مع كود QR.

---

## 🛠 التقنيات المستخدمة (Tech Stack)
* **الواجهة الأمامية (Frontend):** React 18، TypeScript، Tailwind CSS، Lucide Icons، Vite.
* **معمارية الذكاء الاصطناعي (AI & Logic Layer):** Closed-Domain Semantic RAG، Prompt Engineering، Contextual Verification Guardrails.
* **التخزين والمزامنة:** LocalStorage State Engine مع حفظ التقدم وسلسلة الأيام المكتملة.
* **التصميم وإمكانية الوصول:** دعم كامل للاتجاهين (RTL/LTR) واللغات العربية والإنجليزية والأوردية.

## 💻 طريقة التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات المسبقة:
* Node.js الإصدار 18.0 أو أحدث.
* مدير الحزم `npm` أو `pnpm`.

### خطوات التثبيت:
1. استنساخ المستودع (Clone repository):
```bash
git clone https://github.com/team-nex/ilm-platform.git
cd ilm-platform
```

2. تثبيت الحزم والمكتبات (Install dependencies):
```bash
npm install
```

3. تشغيل خادم التطوير المحلي (Start dev server):
```bash
npm run dev
```
افتح المتصفح على العنوان: `http://localhost:3000`

4. فحص الأخطاء والبناء للإنتاج (Lint & Production Build):
```bash
npm run lint
npm run build
```
