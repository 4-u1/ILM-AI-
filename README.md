## 🌟 نظرة عامة (Executive Overview)
**«عِلم | ILM»** منصة تعليمية ودعوية رقمية استثنائية تدمج بين دقة ورصانة العلوم الشرعية المعتمدة وقوة الذكاء الاصطناعي التوليدي المؤطر. تهدف المنصة إلى استبدال أسلوب التلقي النمطي برحلات معرفية تفاعلية متدرجة مخصصة للمسلم الأصيل، المسلم الجديد، غير المسلم، والداعية، مع ضمان الإسناد الفوري بنسبة **100% لمصادر موثقة** وتطبيق سياج حماية شرعي حاسم يمنع الفتوى الآلية المستقلة.

- 📄 **رابط الوثيقة الكاملة:** [PRD.md](./PRD.md)

  - مواصفات المعلم الحواري الذكي (قاعدة السؤال الواحد، الكبسولات المصغرة 30-50 كلمة).

  - سياسة سياج الحماية الشرعي (Guardrails Protocol) وضمان عدم الفتوى الآلية في المستوى (د).

## 🚀 الركائز التقنية الأساسية (Key Architectural Pillars)
* **المعلم الحواري الذكي (Conversational AI Mentor):** أسلوب تدريس حواري نشط (*Learna-Style*) يقسم الدرس إلى كبسولات معرفية محكمة، لا تنتقل للمفهوم التالي إلا بعد قياس فهم واستيعاب المتعلم تفاعلياً.
* **محرك الـ RAG الشرعي الموثوق (Deterministic Curated In-Memory RAG):** محرك استرجاع معرفي حتمي مقيد بسياق المنهج المعتمد والمصادر الرسمية المحددة في التحدي (مجمع الملك فهد لطباعة المصحف الشريف، موسوعة الدرر السنية، المستودع الدعوي الرقمي، وموسوعة الجمهرة)، مما يضمن نسبة 0% هلوسة مع توفير إسناد كامل وبطاقة استعراض للمصدر مع كل إجابة.
* **سياج الحماية الشرعية (Strict Guardrails & 0% Autonomous Fatwa):** نظام عزل وتصعيد فوري يمتنع آلياً عن الفتوى في النوازل والأحوال الشخصية والنزاعات ويحيل للمرجعيات والإدارات الإفتائية الرسمية.
* **تلاوة القرآن الكريم بالنقر (Click-to-Recite):** تشغيل التلاوة الصوتية المرتلة للآيات الكريمة مباشرة من مصحف مجمع الملك فهد (بصوت الشيخ مشاري العفاسي) مع محرك نطق احتياطي عبر `Web Speech API`.
* **محاكي الدعوة التفاعلي (Daiyah Simulator):** بيئة تدريب واقعية لتدريب الدعاة على مناقشة الشبهات وتحليل الأداء الاستدلالي والإقناعي فورياً بتقرير بياني تفصيلي.
* **منظومة سفراء عِلم للدعوة التفاعلية (ILM Ambassadors Hub):** رابط دعوة تتبعي ذكي مع لوحة أثر حي وأوسمة تدرجية تسخّر طاقة عموم المسلمين للمساهمة في التعريف بالإسلام.
* **المساعد الدعوي الميداني الفوري (Real-time Whispering Co-Pilot):** درع معرفي سريع يوفر الحجة العقلية، الدليل الشرعي، وأدب الحوار لمواجهة الشبهات في ثوانٍ.
* **برنامج الأيام الـ 30 الأولى للمهتدي (First 30 Days Foundations):** منهج يومي عملي ميسر خطوة بخطوة ودعاء نبوي يقي المسلم الجديد من التشتت.
* **حقيبة العمل دون إنترنت (Offline-First & Field Kit):** إمكانية تحميل المسارات والاختبارات والتصفح الكامل دون اتصال بالشبكة في السفر والميدان.
* **التوأم الرقمي للفتوى والإحالة المعتمدة (Official Fatwa Referral Protocol):** بروتوكول توجيه وإحالة إرشادية رسمي يربط المستفيد مباشرة بالمواقع والمنصات المعتمدة للإفتاء لمنع الفتوى الآلية المستقلة (المستوى د).
* **نظام الإشعارات الذكي المعزز بالذكاء الاصطناعي (AI Smart Push Notifications):** خوارزمية ذكية تحلل نشاط المستخدم وفترات انقطاعه لترسل له إشعاراً تشجيعياً مخصصاً في وقت فراغه المفضل (صباحاً، ظهيرة، مساءً، ليلاً) مع حديث نبوي مأثور عن المداومة.
* **لوحة التحليلات والتحفيز الذاتي:** تتبع سلسلة التعلم اليومية (*Daily Streak Counter*)، وأوسمة الإنجاز الرقمية (*XP Badges*)، ورسوم بيانية لوتيرة التعلم وساعات المدارسة باستخدام `recharts`.
* **شهادة إتمام معتمدة ومشاركة الإنجاز:** محرك توليد شهادة رقمية ملكية مع كود QR فريد للتحقق وبطاقة بصرية قابلة للمشاركة على وسائل التواصل الاجتماعي.

## 🛠 التقنيات المستخدمة (Tech Stack)
* **الواجهة الأمامية (Frontend):** React 19، TypeScript 5.7، Tailwind CSS v4، Lucide Icons، Recharts، Vite.
* **خادم التطبيق ووكيل الـ AI (Backend & Proxy):** Node.js، Express، `@google/genai SDK v2.4.0` (Gemini 3.8 Flash & 3.1 Flash Lite Fallback).
* **الاسترجاع المعرفي (Knowledge Retrieval):** Closed-Domain RAG، Semantic Context Injection، Prompt Guardrails.
* **التخزين والمزامنة:** LocalStorage State Engine الآمن مع حفظ تقدم المحطات والشهادات.
* **التصميم والتوافق:** دعم كامل للاتجاهين (RTL/LTR) واللغات العربية والإنجليزية والأوردية.

## 💻 طريقة التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات المسبقة:
* Node.js الإصدار 18.0 أو أحدث.
* مدير الحزم `npm`.

### خطوات التثبيت:
1. استنساخ المستودع (Clone repository):
```bash
git clone https://github.com/team-nex/ilm-platform.git
cd ilm-platform
```

2. تثبيت الحزم والمكتبات (Install dependencies):
```bash
npm install
```

3. تشغيل خادم التطوير المحلي (Start dev server):
```bash
npm run dev
```
افتح المتصفح على العنوان: `http://localhost:3000` أو تصفح المنصة مباشرة عبر [https://weilmai.ai.studio/](https://weilmai.ai.studio/).

4. فحص الأخطاء والبناء للإنتاج (Lint & Production Build):
```bash
npm run lint
npm run build
```
